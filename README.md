
# gitfame

Утилита командной строки для подсчёта статистик авторов Git-репозитория: количество строк, коммитов и файлов, относящихся к каждому автору по состоянию на заданный коммит.

Особенности

- Подсчёт строк, коммитов и файлов для каждого автора.
- Использует `git blame --porcelain` для привязки строк к последним коммитам.
- Фильтрация по расширениям, по языкам (см. `configs/language_extensions.json`), glob-исключениям и restrict-to паттернам.
- Поддержка форматов вывода: `tabular`, `csv`, `json`, `json-lines`.
- Опция `--use-committer` для использования коммиттера вместо автора.
- Прогресс можно выводить в `stderr`.

Сборка

Собрать исполняемый файл из поддиректории с командой:

```bash
make build
```

Установка в `GOPATH/bin`:

```bash
make install
export PATH=$GOPATH/bin:$PATH
```

Использование

Запуск примера (текущая директория как репозиторий):

```bash
make run
```

Краткий список флагов

- `--repository` — путь до Git-репозитория (по умолчанию текущая директория)
- `--revision` — указатель на коммит (по умолчанию `HEAD`)
- `--order-by` — `lines` (по умолчанию), `commits`, `files`
- `--use-committer` — использовать committer вместо author
- `--format` — `tabular` (по умолчанию), `csv`, `json`, `json-lines`
- `--extensions` — список расширений через запятую, например `.go,.md`
- `--languages` — список языков (совпадает через `configs/language_extensions.json`)
- `--exclude` — набор glob-паттернов для исключения файлов
- `--restrict-to` — набор glob-паттернов; допускаются только файлы, соответствующие хотя бы одному паттерну

Формат вывода

- `tabular` — человеко-читаемая таблица (используется пробел для выравнивания)
- `csv` — стандартный CSV
- `json` — массив объектов
- `json-lines` — одна JSON-структура на строку

Тесты

Интеграционные тесты используют заранее подготовленные git-бандлы в `test/integration/testdata/bundles`.

Запуск тестов:

```bash
make test
```
Замечания

- Утилита не изменяет состояние репозитория (не выполняет checkout, reset и т.п.).
- При ошибках или неверных флагах программа завершится с ненулевым кодом возврата и выведет сообщение в `stderr`.
- Подсчёт может занимать время; используйте вывод прогресса для контроля.

Где смотреть код

Реализация командной строки находится в `gitfame/cmd/gitfame`, основная логика — в `internal/`.
